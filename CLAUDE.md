# Social Media Team repo

Agents and skills for the Social Media Team: trend and outlier research on TikTok, Instagram, Facebook, YouTube and X, reference-video breakdowns, organic content plans and calendars, captions, community replies, and micro-influencer seeding. Start with `README.md`. For partner teams, see `COLLABORATION.md`.

## Rules for anyone editing this repo
- **Treat this repo as if it were public.** Never commit API keys, `.env`, logins, performance numbers, influencer contact details, DMs, comments from real people, unreleased campaigns, or Offer Sheet prices. Those live only in Google Drive › Provex Sports › Marketing › Marketing & Social Media Team.
- `social/references/social-guardrails.md` binds every agent and overrides individual agent files. Creative's `creative-guardrails.md` §2–§4 (claims, likeness, AI disclosure) apply here too; where the two differ, the stricter rule wins.
- Learning runs may edit only the knowledge files (`social/references/platform-playbooks.md`, `social/references/ph-calendar.md`, `social/references/content-pillars.md`, and each research skill's `references/`), and only after the owner approves the Learning Update. They never edit agent files or the guardrails.
- Platform facts are dated and sourced. No source, no claim.
- The owner (Angela Lee for Provex Sports) approves changes to agents, guardrails, templates, and claims.
- Don't commit or push without the owner's go-ahead.
