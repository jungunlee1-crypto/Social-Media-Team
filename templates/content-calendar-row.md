# Content Calendar Row

Matches the columns of the Drive sheet "Provex FB-IG Content Calendar" (Marketing & Social Media Team folder), plus four columns for the other platforms and tracking. One row per post; the same post ID across platforms.

| Column | What goes in it |
|---|---|
| # | Post ID (e.g. P-1101-01) |
| Date | e.g. Sun Nov 1 |
| Time (PH) | Asia/Manila |
| Format | Reel, carousel (n slides), static, Story, TikTok, Short, long video, X post, X thread |
| Pillar | Education, Community, Product, Athlete stories |
| Topic / SKU | |
| Hook (on-screen text) | Max 8 words |
| Caption (English) | |
| Taglish hook option | |
| Visual brief | Or the Creative asset ID |
| CTA | |
| Hashtags | 3–5 |
| Status | Draft → QA passed → Ready for owner → Approved – owner posts → Posted |
| Compliance check | social-qa result: Pass / Fix / Block, with the rule |
| Caption (Taglish) | |
| Caption (Tagalog) | |
| OK for FB community groups? | Yes / No, and why |
| *Platforms* | IG, FB, TikTok, YouTube, X |
| *Trend source* | Digest link the post adapts |
| *Sound and source* | Commercial library / licensed / none |
| *X version* | Post or thread text |
